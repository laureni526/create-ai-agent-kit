# Today's Before/After Prompts

*The exact prompts used in the two live tests from the session — run
these yourself, on your own task and your own tools, and notice the
gap the same way the room did.*

## Test 1 — Context (the warm-up)

Same prompt, run twice.

> "Draft a short [social post / message / summary] about [something
> specific to your work]."

**Round 1:** run it in a brand-new conversation with no background
loaded. Read the result as-is — it will likely be generic and require
a rewrite.

**Round 2:** before running the same exact prompt again, give the
agent real background first — who this is for, what's made similar
things land before, and your own voice on the topic. Same words in.
Notice what's different out.

## Test 2 — Planning and goals (the bigger lever)

Same skill loaded both times (use whatever you built from
`skill-starter-template.md`, or the one from the session).

> **Round 1:** "Handle my [inbox / task list / project]."

Notice where it's vague, where it guesses, or where it stalls waiting
on you.

> **Round 2:** "Your goal is [the actual outcome you want, stated
> plainly]. First, [the first thing you'd do yourself]. Then [the
> second]. Then tell me what's left that needs my judgment."

Same skill. Only the goal and the plan changed. That's the whole
lesson: the bigger lever was never the wording of the ask — it's
telling the agent what you're actually trying to accomplish and how
you'd break it down yourself.

## Test 3 — The chief-of-staff test (the capstone)

This is the one to run once you've built a real skill and connected a
real tool.

> "Reply to this real email, in my voice, as my chief of staff would."

**Round 1:** a fresh conversation, no skill, no plan, no connection.
Point it at one real email (or paste one in) and run the prompt as-is.

**Round 2:** your skill loaded, a stated goal (see Test 2's format),
and the agent connected to your real inbox per `connector-primer.md`.
Same task, same words. Check where the draft lands — it should be
sitting in Drafts, not sent, waiting on you.

If Round 2 doesn't feel materially better than Round 1, the fix is
almost never a better prompt. Go back to `skill-starter-template.md`
and make "What it should know" more specific — the same discipline
from today's live build.
